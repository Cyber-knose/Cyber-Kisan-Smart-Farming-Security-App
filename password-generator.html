Password Security Tips

  • Length: Use at least 12 characters for better security
  • Mix: Combine uppercase, lowercase, numbers & symbols
  • Avoid: Don't use personal information like names, birthdays
  • Unique: Use different passwords for different accounts
  • Update: Change passwords regularly, especially for banking
  • Store Safely: Never write passwords in plain text
